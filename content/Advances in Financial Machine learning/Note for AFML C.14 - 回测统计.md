## 回测统计
在本章中，我们将讨论一些最常用的绩效评估统计数据。其中一些统计数据包含在《全球投资绩效标准》（GIPS）中，然而，全面的绩效分析还需要针对所研究的机器学习策略的特定指标。
### 回测统计类型
分为一般特征、绩效、运行/回撤、实施不足、回报/风险效率、分类评分和归因。
### 一般特征
- 时间范围：时间范围指定了起始日期和结束日期。用于测试策略的时间段应足够长，以包含大量不同的市场状态
- 平均管理资产规模（AUM）：这是管理资产的平均美元价值。在计算此平均值时，多头和空头头寸的美元价值均视为正实数。
- 容量：策略的容量可以被衡量为在实现目标风险调整收益的情况下能够管理的最高资产管理规模
- 杠杆：杠杆衡量实现报告业绩所需的借款金额。
- 最大美元头寸规模：最大美元头寸规模告诉我们策略是否在某些时候采取了远超平均资产管理规模的美元头寸。一般来说，我们更倾向于选择最大美元头寸接近平均资产管理规模的策略，这表明它们不依赖于极端事件的发生（可能是异常值）。
- 多头比例：多头比例显示参与的投注中多头仓位所占的比例。
- 投注频率：投注频率是回测中每年的投注次数。同一方向的一系列仓位被视为同一次投注。当仓位被平仓或转换到相反方向时，投注结束。投注次数总是少于交易次数。交易次数会高估策略发现的独立机会数量。
- 平均持有期：平均持有期是指一笔投注被持有的平均天数。
- 年化周换手率：年化周转率衡量每年交易的平均金额与平均年度资产管理规模（AUM）之比。
- 与标的相关性：这是策略回报与标的投资组合回报之间的相关性。当相关性显著为正或负时，该策略本质上是持有或做空投资组合，而没有增加太多价值。
### 绩效
业绩统计是未进行风险调整的美元和回报数据。一些有用的业绩衡量指标包括：
- PnL：在整个回测期间产生的总金额（以美元或面值货币的等值计算），包括终端持仓的清算成本。
- 多头头寸的盈亏：仅由多头头寸产生的盈亏部分。
- 年化收益率：包括股息、票息、费用等在内的总回报的时间加权平均年化率。
- 命中率：导致正收益的投注比例。
- 平均命中回报：从产生利润的投注中获得的平均回报。
- 未命中投注的平均回报：指产生亏损的投注的平均回报。
#### 时间加权收益率
总回报是指在计量期间内，来自实现和未实现的收益与损失的回报率，包括应计利息、已支付的利息和股息。GIPS 规则计算经过外部现金流调整的时间加权收益率（TWRR）。周期性和子周期性收益率通过几何方式连接。*好复杂的计算，没仔细看。*
### 运行
投资策略很少会产生来自独立同分布（IID）过程的收益。在缺乏这种特性的情况下，策略收益序列会表现出频繁的连续波动。连续波动是指同号收益的连续序列。因此，连续波动会增加下行风险，需要通过适当的指标进行评估。
#### 收益的集中度
对收益序列$r_t$分成正负两部分，得到$r^+_t$和$r^-_t$, 对全样本上归一化得到$w_t^+$和$w_t^-$。可以计算正收益的集中度为
$$h^+ = \frac{\sum_t (w_t^+)^2 - \|w^+\|^{-1}}{1 - \|w^+\|^{-1}} = \left(\frac{E[(r_t^+)^2]}{E[r_t^+]^2} -1 \right)(\|r^+\| -1)^{-1}$$
和负收益的集中度
$$h^- = \frac{\sum_t (w_t^-)^2 - \|w^-\|^{-1}}{1 - \|w^-\|^{-1}} = \left(\frac{E[(r_t^-)^2]}{E[r_t^-]^2} -1 \right)(\|r^-\| -1)^{-1}$$
其中$\|\cdot\|$表示向量的大小(*应该是非零项的个数*)。这个指标有一些有趣的特性：
1. $0 \leq h \leq 1$
2. $h^+ =0 \Leftrightarrow w_t^+ = \|w^+\|^{-1}$，收益是均匀的。
3. $h^+ = 1$ 表明只有一个正收益。
同样的，也可以计算下注规模的集中度。
理想情况下，我们感兴趣的是那些投注收益表现出以下特征的策略：
- 高夏普比率
- 高下注次数
- 高命中率
- 低正收益集中度
- 低负收益集中度
- 低下注集中度
#### 回撤与水下时间
回撤（DD）是指投资在两个连续高点（HWM）之间所遭受的最大损失。水下时间（TuW）是指从一个高点到收益超过之前最高收益的时间间隔。
#### 性能评估运行统计
- 正收益的HHI指数
- 负收益的HHI指数
- 投注间隔时间的HHI指数
- 95分数数回撤
- 95分位数水下时间
### 执行不足
投资策略经常因对执行成本的错误假设而失败。一些重要的衡量指标包括：
- 每笔交易的经纪费：这是支付给经纪人的费用，用于处理投资组合的交易，包括交易所费用。
- 每次组合周转的平均滑点：这些是执行成本，不包括经纪费用，涉及一次组合周转。
- 每次交易的美元表现：这是美元表现（包括经纪费用和滑点成本）与投资组合总周转率之间的比率。
- 执行成本回报：这是美元收益（包括经纪费用和滑点成本）与总执行成本之间的比率。
### 效率
#### 夏普比率
SR 的目的是评估特定策略或投资者的技能。不可避免的结果是，夏普比率的计算可能会存在较大的估计误差。
#### 概率夏普比率
概率夏普比率（PSR）通过消除由偏斜和/或厚尾收益的小样本序列引起的膨胀效应，提供了对夏普比率（SR）的调整估计。给定用户定义的基准夏普比率$SR^*$（这可以设置为默认值零，即与没有投资技能进行比较）和观察到的夏普比率$\hat{SR}$，$PSR$ 估计$\hat{SR}$ 大于假设 $SR^*$ 的概率
$$\hat{PSR}[SR^*] = Z\left[\frac{(\hat{SR} - SR^*)\sqrt{T-1}}{\sqrt{1 - \hat{\gamma}_3\hat{SR} + \frac{\hat{\gamma}_4-1}{4}\hat{SR}^2}}\right],$$
其中，$\hat{\gamma}_3,\hat{\gamma}_4$分别是收益率序列偏度和峰度的估计。
#### 膨胀调整后的夏普比率
膨胀调整后的夏普比率（DSR）是一种概率夏普比率（PSR），其拒绝阈值经过调整以反映多次试验的情况。考虑多次实验的情况，在PSR中，基准夏普比率$SR^*$被估计为
$$SR^* = \sqrt{V[\{\hat{SR}_n\}]}\left((1-\gamma)Z^{-1}\left[1-\frac{1}{N}\right] + \gamma Z^{-1}\left[1-\frac{1}{eN}\right]\right)$$
其中$V[\{\hat{SR}_n\}]$是各试验的夏普比率估计值的方差，$\gamma$是欧拉常数，$N$是独立实验的次数。
DSR 的基本原理如下：给定一组 Sharpe 比率的估计值$\{\hat{SR}_n\}$，其期望最大值大于零。在零假设下，即实际 Sharpe 比率为零时(*这里注意，为了满足这个条件，我们需要排除手续费和spread*)，多次实验得到的最大值夏普比率可以被拟合为$SR^*$。实际上，随着尝试的独立实验次数$N$增多，或者实验涉及更大的方差, 基准夏普比率$SR^*$则会飞速增长。
#### 马尔科斯的第三回测法则
每个回测结果都必须与其产生过程中涉及的所有试验一起报告。如果没有这些信息，就无法评估回测的“虚假发现”概率。
#### 效率统计
- 年化夏普比率：这是通过因子$\sqrt{a}$进行年化的SR值，其中$a$是每年观察到的平均收益次数。这种常见的年化方法基于收益是独立同分布（IID）的假设。
- 信息比率：这是投资组合的夏普比率等效指标，用于衡量其相对于基准的表现。它是平均超额收益与跟踪误差之间的年化比率。超额收益是指投资组合回报超过基准回报的部分。跟踪误差估算为超额收益的标准差。
- 概率夏普比率：PSR 修正了由于非正态收益或业绩记录长度引起的通胀效应对夏普比率的影响。它可以基于绝对收益或相对收益进行计算。一个有效的发现应该达到95%置信度。
- 贬值夏普比率：DSR 对因非正态收益、业绩记录长度以及多重测试/选择偏差引起的通胀效应对 SR 进行了修正。。一个有效的发现应该在考虑多次重复是实验的情况下达到95%置信度。它可以基于绝对收益或相对收益进行计算。
### 分类分数
在元标签策略的背景下[[Note for AFML C.3 - 标签#元标注]]，理解机器学习覆盖算法的独立表现是很有用的。请记住，主要算法负责识别机会，而次要（覆盖）算法则决定是否把握这些机会或放弃。一些有用的统计数据包括：
- 准确性：准确性是覆盖算法正确标注的机会的比例
- 精确率：精确率是预测为正例中真实为正例的比例
- 召回率：召回率是在所有正样本中真实为正的比例
- F1：精确率和召回率的调和平均。对于元标注应用，准确率可能不是一个充分的分类评分，F1 分数可以纠正这个缺陷。**另外，F1的表现取决的正样本比例，一半来说，保持正样本是较少的那一方才能保证F1指标有效。**
- 负对数损失：准确率和负对数损失之间的关键概念区别在于，负对数损失不仅考虑我们的预测是否正确，还考虑这些预测的概率。
### 归因
风险之间往往并非正交，它们之间总是存在重叠。各风险类别的归因盈亏之和将与总盈亏不一致，但至少我们可以计算每个风险类别的夏普比率（或信息比率）。最受欢迎的例子可能是Barra的多因子方法。
同样值得关注的是在每个分类内按类别分配盈亏。
1. 为了避免前面提到的重叠问题，我们需要确保投资组合中的每个成员在任何时间点都只属于每个风险类别中的一个类别。
2. 对于每个风险类别，我们为每个风险类别形成一个指数。每个指数的权重是我们投资组合的重新调整后的权重，因此每个指数的权重加起来为1。
3. 重复第二步，但这次我们使用投资组合范围的权重，形成那些风险类别指数，同样重新调整，使每个指数的权重加起来为1。
4. 计算本章前面讨论的每个指数收益和超额收益的表现指标。
