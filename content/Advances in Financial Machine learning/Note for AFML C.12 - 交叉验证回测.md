## 通过交叉验证进行回测
### 前向滚动法
WF 是一种历史模拟，用于评估策略在过去的表现如何。每个策略决策都是基于早于该决策的观察结果。
不幸的是，没有通用的回测方法。为了准确和具代表性，每一次回测都必须针对特定策略的假设进行定制。
**优势**：
- 有明确的历史解释，表现可以与模拟交易对应
- 历史数据是一种过滤；因此，使用滞后数据可以保证测试集是样本外数据
在WF回测中不需要禁运(embargoing)，因为训练集总是早于测试集。
#### 前向滚动法的陷阱
**WF的缺点**：
- 只测试单一场景（历史路径），这很容易导致过拟合
- WF不一定能够代表未来表现，因为结果可能会受到数据点特定序列的偏差。
- 初始决策是基于总样本的一小部分做出的，因为存在预热期
### 交叉验证法
通过交叉验证（CV）进行回测的目标不是为了获取历史上准确的表现，而是从多个样本外的情景中推断未来的表现。在回测的每个阶段，我们模拟了一个分类器的表现，该分类器除了这一期间之外了解所有信息。
**优点**：
1. 该测试并不是某个特定（历史）情境的结果
2. 每个决策都是在相等规模的集合上做出的。
3. 每个观测值都属于唯一的一个测试集。没有预热子集，从而实现最长可能的样本外模拟。

**缺点**：
1. 像WF一样，模拟了单一路径的回测（虽然不是历史路径）。每个观测值仅生成一个预测。
2. CV没有明确的历史解释。其输出并不模拟该策略在过去的表现，而是模拟在各种压力情景下未来可能的表现
3. 由于训练集并不落后于测试集，因此可能会发生信息泄露。必须极其小心，以避免测试信息泄露到训练集中。[[Note for AFML C.7 - 交叉验证#清除后的k折交叉验证]]
### 组合式清洗交叉验证方法(CPCV)
给定研究者目标的回测路径数量$\varphi$，CPCV生成所需的训练/测试集组合的精确数量以生成这些路径，同时清除包含泄露信息的训练观测值。
#### 组合拆分
把$T$个观察拆分为$N$组，对于测试集占据其中$k$组的划分，有$N!/(k!(N-k)!)$种。则总计被测试的组数还要再乘$k$. 我们可以回测的总路径数为$\varphi[N,k] = \frac{k}{N}\binom{N}{k}$. 
这些路径是通过在每个组合的数据的一个比例 $\theta = 1-k/N$上训练分类器生成的。路径的数量随着$N \to T$和$k \to N/2$增加。
#### 组合清除交叉验证回测算法
1. 将$T$个观测值不打乱地分成均匀的$N$组
2. 计算所有可能的训练/测试划分，$N-k$个组为训练集，$k$组为测试集
3. 对于任何标签$(y_i,y_j)$，其中$y_i,y_j$分别属于训练集和测试集，如果$y_i$的时间段与$y_j$有重叠，则清除$y_i$。如果某些测试样本的时间早于某些训练样本，该类还会施加禁运期。
4. 在$\binom{N}{N-k}$个训练集上拟合分类器，在对应的测试集上预测
5. 计算出对应的$\varphi[N,k]$个回测路径。你可以从每条路径计算一个夏普比率，然后从中得出策略夏普比率的经验分布
#### 例子
当$k=1$, $\varphi[N,1] = 1$,退化成简单的cv。当$k=2$, $\varphi[N,2] = N-1$。这意味着，我们可以简单划分成$N = \varphi +1$组，然后构成$\binom{N}{2}$的组合。
### 组合清除交叉验证如何解决回测过拟合问题
给出$I$个独立的标准正态分布变量$x_i$, 则其最大值的期望为
$$E[\max_i x_i] \approx (1-\gamma) Z^{-1}[1-\frac{1}{I}] + \gamma Z^{-1}[1-\frac{1}{Ie}] \leq \sqrt{2\log I},$$
其中，$Z[\cdot]$是标准正态分布的累计分布函数，$\gamma$是欧拉常数。
现在假设对一个表现像鞅的标的研究，$\frac{y_i}{\sigma[y_i]} \sim Z.$ 即使真实的夏普比率为零，我们仍然期望找到一个策略的夏普比率为
$$E[\max_i y_i] = E[\max_i x_i] \sigma[y_i].$$

WF 回测表现出高方差，$\sigma[y_i] >0$, 至少有一个原因：大量决策基于数据集的一小部分.
一些观测值在夏普比率上将占有很大权重。使用热身期会缩短回测长度，这可能进一步增加方差。WF 的高方差会导致虚假发现，因为研究人员会选择具有最大估计夏普比率的回测，即使真实夏普比率为零。这就是为什么在 WF 回测背景下必须控制试验次数 (I) 的原因。没有这些信息，就无法确定全体错误率 (FWER)、虚假发现率 (FDR)、回测过度拟合概率[[Note for AFML C.11 - 回测的危险#PBO]] 或类似的模型评估统计指标。
CV回测通过在数据集的相等且较大的部分上训练每个分类器来解决这种方差来源。尽管CV比WF导致的假发现更少，这两种方法仍然只是从策略$i$的单一路径$y_i$中估计夏普比率，而这种估计可能高度波动。
相比之下，CPCV通过大量路径$j = 1,...,\varphi$推导夏普比率的分布，其均值为$E[\{y_{i,j}\}_{j=1,...,\varphi}] = \mu_i$，方差为$\sigma^2[\{y_{i,j}\}_{j=1,...,\varphi}] = \sigma_i^2$。CPCV路径样本均值的方差为
$$\sigma^2[\mu_i] = \varphi^{-2}(\varphi\sigma_i^2 + \varphi(\varphi-1)\sigma_i^2\bar{\rho}_i) = \varphi^{-1}\sigma_i^2(1+(\varphi-1)\bar{\rho}_i),$$
其中$\sigma_i^2$是夏普比率在策略$i$上不同路径的方差, $\bar{\rho}_i$是$y_{i,j}$的平均非对角相关性。
CPCV 导致较少的误报， 因为$\bar{\rho}_i<1$意味着样本均值的方差小于样本的方差。
路径之间的不相关性越高，CPCV的方差就越低，选择偏差的概率就越小。
