## 下注规模
*如果你没有合理地控制下注规模，你的投资策略必然会亏钱*
### 独立于策略的下注规模方法
设$m_{i,t}\in[-1,1]$为策略$i$在时间$t$的投注规模，其中$m_{i,t}=-1$表示完全做空，$m_{i,t}=1$表示完全做多。
我们希望保留现金以应对交易信号强弱的变化。一种方法是$c_t=c_{t,l}-c_{t,s}$,把仓位分成做多和做空两部分。拟合二高斯混合模型，得到下注规模为
$$m_t = \frac{F[c_t]-F[0]}{1-F[0]}I\{c_t\ge0\} + \frac{F[c_t]-F[0]}{F[0]}I\{c_t<0\},$$
其中，$F[x]$是拟合分布的累计分布函数。
第二种方法是使用预算方法。计算最大数量的多头下注和做大数量的空头下注。做minmax归一化，即
$$m_t = \frac{c_{t,l}}{\max_i\{c_{i,l}\}}-\frac{c_{t,s}}{\max_i\{c_{i,s}\}}$$
第三种方式是应用元标签。训练一个分类器，用来确定误分类的概率，利用该概率来推到投注大小。这个方法的优点是：决定投注大小的算法独立于主模型，从而可以纳入预测假阳性的特征。[[Note for AFML C.2 - 数据结构#元标注]]同时，预测概率可以直接转换为投注大小。
### 根据预测概率进行投注大小
令$p[x]$是标签$x$发生的概率。对于二元分类标签，我们的原假设为$H_0:p[x] = 1/2.$则统计量
$$z = \frac{p[x=1] - 0.5}{\sqrt{p[x=1](1-p[x=1])}} \sim \mathcal{N}(0,1).$$
则我们的下注规模可以设置为$m=2Z[z]-1$,$Z[\cdot]$是标准正态分布的累计分布函数。
对于多于2种结果的情形，可以采用一对多的方法。对于每个标签$i$, 估计概率$p_i$满足$\sum_i p_i =1$. 定义$\tilde{p}=\max_i p_i$, 原假设为$H_0: \tilde{p} = \frac{1}{\|X\|}$.使用同样的统计量，则下注规模为$m = x(2Z[z]-1)$,表示对于最大标签$x$的下注规模。 
*这里的处理手法就太粗糙了，一堆随机变量最大值的分布距离标准分布偏差甚远，应当慎重*
### 平均活跃投注
每笔投注都和一个持有期相关联，从其产生的时间到第一个障碍被触及的时间$t_1$。[[Note for AFML C.2 - 数据结构#三重障碍方法]]一种方法是在新投注到来时覆盖旧投注，但是这可能导致过高的交易频率。
更合理的方法是，在给定时间点对所有仍然活跃的投注进行规模平均。(*需要研读实现代码*)
### 尺寸离散化
平均化可以减少一些过度的交易，但仍然可能每次预测都会触发小额交易。为了避免这些抖动导致的过度交易，应当对下注规模离散化: $m^*=\text{round}[m/d]d$.
### 动态投注额和限制价格
回顾三重障碍标注法。第$i$个障碍在时间$t_{i,0}$形成，尝试预测首先触及的障碍。该预测意味着一个预测价格，$E_{t_{i,0}}[p_{t_{i,1}}]$ 与障碍的设置一致。此节将介绍在市场价格$p_t$和预测价格$f_i$波动时调整下注金额的方法。
设$q_t$为当前持仓， $Q$为最大持仓量，$\hat{q}_{i,t}$是与预测$f_{i}$相关的目标持仓量，使得
$$\hat{q}_{i,t} = int[m[\omega, f_i - p_t]Q], 
\quad
m[\omega, x] = \frac{x}{\sqrt{\omega+x^2}}, 
$$
其中 $m[\omega, x]$是下注规模，$x = f_i - p_t$是现价和预测价之间的差异，$\omega$是sigmoid函数中的正则系数。
头寸规模$\hat{q}_{i,t}$可以随着$p_t$的变化而动态调整，特别是，当$p_t \to f_i$，我们得到$\hat{q}_{i,t} \to 0$. 这意味着，对于头寸规模$\hat{q}_{i,t} - q_t$, 有一个盈亏平衡的限价$\bar{p}$，以避免亏损，
$$\bar{p} = \frac{1}{|\hat{q}_{i,t} - q_t|} \sum_{j = |q_t +sign[\hat{q}_{i,t} - q_t]|}^{|\hat{q}_{i,t}| } L[f_i, \omega, \frac{j}{Q}],$$
其中 
$$L[f_i,\omega, m] = f_i - m \sqrt{\frac{\omega}{1-m^2}}.$$
我们不需要担心$m^2=1$的情况，因为$|\hat{q}_{i,t}|<1$。由于该函数是单调的，当$p_t \to f_i$时，算法无法实现损失。(*何意味？？？*)
给定用户定义的$(x,m^*)$, 可以推导出需要的参数$\omega = x^2({m^{*}}^{-2} -1).$
#### 示例
首先，我们校准 sigmoid 函数，使其在价格偏差 $x = 10$ 时返回下注大小 $m^* = 0.95$。其次，我们计算目标头寸$\hat{q}_{i,t}$，当最大头寸 $Q = 100$、$f_i = 115$ 且 $p_t = 100$。如果你尝试 $f_i = 110$，你将得到$\hat{q}_{i,t} = 95$，这与$\omega$的校准一致。第三，这个大小为$\hat{q}_{i,t} − q_t = 97$的订单的限价为 $p_t < 112.3657 < f_i$，位于当前价格与预测价格之间。

作为S形函数的替代方案，我们可以使用幂函数$m[\omega, x] = sign[x]|x|^\omega$,这种方案的优势是：
1. $\tilde{m}[\omega, -1] = -1, \tilde{m}[\omega, 1] = 1.$
2. 曲率可以直接通过$\omega$控制。
3. 对于$\omega>1$，函数从凹形变为凸形，而不是相反，因此函数在拐点附近几乎是平的。
