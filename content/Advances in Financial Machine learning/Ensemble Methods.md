## 集成方法
Bagging可以降低方差，但不能提高准确率。
如果每个时间点 t 的观察值按 t 和 t+100 之间的收益来标记，我们应该为每个装袋估计器抽取 1% 的观察数据，但不要更多。
### 随机森林
防止过拟合的方法：
1. 将参数 max_features 设置为较低的值，以此作为强制树之间出现差异的一种方法
2. 早停：将正则化参数 min_weight_fraction_leaf 设置为足够大的值（例如 5%），以使袋外准确率收敛到样本外（k 折）准确率。
3. 在 DecisionTreeClassifier 上使用 BaggingClassifier，其中 max_samples 设置为样本之间的平均唯一性 (avgU)。
	```
	clf=DecisionTreeClassifier(criterion='entropy',max_ features='auto',class_weight='balanced')
	bc=BaggingClassifier(base_estimator=clf,n_estimators= 1000,max_samples=avgU,max_features=1.)
	```
4. 在 RandomForestClassifier 上使用 BaggingClassifier，其中 max_samples 设置为样本之间的平均唯一性（avgU）。
	```
	clf=RandomForestClassifier(n_estimators=1,criterion= 'entropy',bootstrap=False,class_weight='balanced_ subsample')
	bc=BaggingClassifier(base_estimator=clf,n_estimators= 1000,max_samples=avgU,max_features=1.)
	```
5. 修改 RF 类，将标准自助法替换为顺序自助法。
在拟合决策树时，将特征空间旋转到与坐标轴对齐的方向通常可以减少树所需的层数。因此，我建议你在对特征进行 PCA 后再拟合随机森林，因为这可能加快计算速度并减少一些过拟合
### 增强方法在金融中
bagging和boosting主要有以下几点不同：
- 各个分类器是依次进行拟合的。
- 表现不佳的分类器会被淘汰。
- 每次迭代中，观察值的权重不同。
- 集成预测是各个学习器的加权平均。
提升的主要优势在于它可以减少预测中的方差和偏差。然而，纠正偏差的代价是增加了过拟合的风险。
可以认为，在金融应用中，通常袋装法比提升法更可取。袋装法解决的是过拟合问题，而提升法解决的是欠拟合问题。过拟合通常比欠拟合更值得关注，因为由于信噪比低，机器学习算法很容易在金融数据上发生过拟合。此外，袋装法可以并行处理，而通常提升法需要顺序运行。
### 为了可扩展性进行装袋
支持向量机（SVM）就是一个典型例子。如果你尝试在一百万个样本上拟合SVM，算法可能需要一段时间才能收敛。即便算法收敛了，也不能保证所得到的解是全局最优，或者没有过拟合。
一种实际的方法是构建一个装袋算法，其中基础估计器属于对样本量不易扩展的类别。
鉴于装袋算法可以并行化，我们将一个大型的顺序任务转换为许多可以同时运行的小任务。当然，提前停止会增加各个基础估计器输出的方差；然而，这种增加可以被装袋算法带来的方差降低所弥补。你可以通过增加更多独立的基础估计器来控制这种降低。以这种方式使用时，装袋算法将使你能够在极其大型的数据集上获得快速且稳健的估计。
## 金融中的交叉验证
CV 是标准机器学习技术在应用于金融问题时再次失败的一个例子。过拟合会发生，而 CV 无法检测到它。
k 折交叉验证在金融领域失效的一个原因是无法假设观察值是从 IID 过程抽取的。交叉验证失败的第二个原因是，在模型开发过程中测试集被多次使用，从而导致多重测试和选择偏差。
Xi 和 Xj 是基于重叠信息形成的，其中 i 属于训练集，而 j 属于测试集。这算是信息泄露吗？不一定，只要 Yi 和 Yj 是独立的。要发生泄露，必须满足 (Xi,Yi) ≈ (Xj,Yj)，而仅仅 Xi ≈ Xj 或者 Yi ≈ Yj 并不足够。
### 清除后的k折交叉验证
假设一个测试观测，其标签 Yj 是基于信息集 $\Phi_j$ 决定的。为了防止上一节中描述的那类信息泄露，我们将从训练集中清除任何其标签 Yi 是基于信息集 $\Phi_i$ 决定的观测，使得 $\Phi_i\cap\Phi_j=\emptyset$。
对于那些清除措施无法防止所有泄漏的情况，我们可以在每个测试集之后对训练观测数据实施禁运。一般来说1%的样本就绰绰有余。
## 特征重要性
在金融研究中最普遍的错误之一是：获取一些数据，将其输入到机器学习算法中，进行回测，然后重复这个顺序，直到出现一个好看的回测结果。所以：
*回测不是一种研究工具。特征重要性才是。*
### 替代效应下的特征重要性
特征重要性方法区分为是否受到替代效应影响是很有用的。在这种情况下，当一个特征的估计重要性因其他相关特征的存在而降低时，就会发生替代效应。解决线性替代效应的一种方法是对原始特征应用主成分分析（PCA），然后在正交特征上进行特征重要性分析。
#### 平均不纯度下降
这是一种专门用于树的快速重要性指标。使用MDI时要注意：
1. 当树模型分类器系统地忽略某些特征而偏向其他特征时，就会产生掩蔽效应。将 max_features 设置为1。这样，每一层只会考虑一个随机特征。
2. 这个过程显然是样本内的。每个特征都会有一定的重要性，即使它们根本没有任何预测能力。
3. MDI 不能推广到其他非树形分类器。
4. 根据构造，MDI 有一个优良的特性，即特征重要性之和为 1，并且每个特征的重要性都在 0 到 1 之间。
5. 该方法未解决存在相关特征时的替代效应。由于可互换性，MDI 会稀释替代特征的重要性。
6. MDI 对某些预测变量存在偏差。在单一决策树的情况下，这种偏差是由于流行的不纯度函数对具有大量类别的预测变量给予了不公平的优势。
#### 平均准确率下降/置换重要性
平均准确度下降是一种缓慢的预测重要性的样本外方法。特征的重要性是由其特征列随机置换置换导致的性能损失决定的。注意事项包括：
1. 这种方法可以应用于任何分类器，而不仅仅是基于树的分类器。
2. MDA并不局限于仅以准确率作为唯一的性能评分。当评分函数不对应于度量空间时，MDA结果应作为排序使用。
3. 像MDI一样，该方法在存在相关特征时也容易受到替代效应的影响。
4. MDA可能会得出所有特征都不重要的结论。这是因为MDA是基于OOS表现的。
5. 使用时配合交叉验证，必须要清理和封存。
### 没有替代效应的特征重要性
替代效应可能会导致我们舍弃一些恰巧是冗余的重要特征。在预测的情况下，这通常不是问题，但当我们试图理解、改进或简化模型时，它可能会导致我们得出错误的结论。
#### 单特征重要性
单个特征重要性是一种横截面预测重要性的样本外方法。计算每个特征单独的样本外表现分数。注意事项包括：
1. 这种方法可以应用于任何分类器，而不仅仅是基于树的分类器。
2. 不限于将准确性作为唯一的性能评分。
3. 不会发生替代效应，因为每次只考虑一个特征。
4. 可以得出所有特征都不重要的结论，因为性能是通过OOS CV评估的。
SFI 的主要限制是，具有两个特征的分类器可能比两个单特征分类器的集成表现更好。SFI 中会丢失联合效应和层次重要性。一种替代方法是计算特征子集的 OOS 性能评分，但随着考虑的特征增多，这种计算将变得不可行。
#### 正交特征
替代效应会削弱MDI衡量的特征的重要性，并显著低估MDA衡量的特征的重要性。部分解决方案是在应用MDI和MDA之前对特征进行正交化。主成分分析（PCA）之类的正交化程序不能完全阻止所有的替代效应，但至少应该能够减轻线性替代效应的影响。
除了处理替代效应之外，使用正交特征还有两个额外的好处：（1）正交化还可以用于降低特征矩阵 X 的维度，通过删除与小特征值相关的特征。这通常可以加快机器学习算法的收敛速度；（2）分析是在旨在解释数据结构的特征上进行的。
PCA 已经在分类意义上对特征进行了排名，而不会出现任何可能的过拟合。当你的 MDI、MDA 或 SFI 分析（使用标签信息）选择与 PCA 相同的特征作为最重要时，这构成了确认性证据，表明机器学习算法识别的模式并非完全过拟合。如果特征是完全随机的，PCA 排名将不会与特征重要性排名相关。
**计算特征重要性与其相关特征值（或等效地，它们的逆PCA排名）之间的加权Kendall秩相关系数很有用。该值越接近1，PCA排名与特征重要性排名之间的一致性就越强。**
### 并行化 VS 堆叠特征重要性
**并行化**是指，特征在不同标的、不同评估标准上都可以计算出一个特征重要性，最后在标的层面聚合。优点是计算速度快，缺点是手提袋效应影响，估计方差会增大。
**特征堆叠**是指，把不同标的的数据集，各自标准化之后合并起来，然后对特征进行重要性评估。优点是，数据集更大，结果直接，结论更稳定，不容易受提袋效应影响。
