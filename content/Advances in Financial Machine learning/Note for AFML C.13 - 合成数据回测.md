## 合成数据回测
### 交易规则
每种投资策略都需要一个实施策略，通常称为“交易规则”。
虽然评估回测过拟合的概率是筛除多余投资策略的有用工具，但在校准交易规则的情况下，最好是避免过拟合的风险。理论上，可以通过直接从生成数据的随机过程导出交易规则的最优参数来实现这一点，而不是进行历史模拟。
### 问题
假设一个投资策略$S$投资于$i = 1,…I$个机会或下注。在每个机会$i$中，$S$持有$m_i$单位的证券$X$，其中$m_i \in (−\infty,\infty)$。进入该机会的交易价格为$m_i P_{i,0}$，其中$P_{i,0}$是交易$m_i$单位证券时的平均单价。随着其他市场参与者交易证券$X$，我们可以在观察到$t$次交易后对机会$i$进行市场定价（MtM），其价值为$m_i P_{i,t}$。因此，可以计算$t$次交易后机会$i$的MtM盈亏为$\pi_{i,t} = m_i(P_{i,t} - P_{i,0})$.
一个标准交易规则提供了在 $t = T_i$时退出机会$i$的逻辑。这会在满足以下两个条件之一时发生：
- $\pi_{i,T_i} \ge \bar{\pi}$, $\bar{\pi}>0$是止盈阈值；
- $\pi_{i,T_i} \leq \underline{\pi}$, $\underline{\pi} < 0$是止损阈值。
这些阈值相当于我们在元标记的语境中讨论的水平障碍。则，策略 $S$ 的交易规则由一组参数$R := \{\bar{\pi},\underline{\pi}\}$决定。
想要校准其中的参数，最暴力的方法就是在历史数据上搜索使sharpe ratio最大的参数组。
由于我们有两个变量用于在样本容量为$I$的情况下最大化 $SR_R$，因此很容易对 $R$ 进行过拟合。当一组$R$针对少数离群值时，就会发生一个平凡的过拟合。
#### 过拟合的交易规则
$R^*$是过拟合的，如果
$$E\left[\frac{E[\pi_{j,T_j}|R^*]}{\sigma[\pi_{j,T_j}|R^*]}\right] < Me_{\Omega}\left[E\left[\frac{E[\pi_{j,T_j}|R]}{\sigma[\pi_{j,T_j}|R]}\right]\right],$$
其中$j=I+1, ..., J$, $Me_{\Omega}[\cdot]$是中位数函数。
直观上，最优的样本内交易规则样本外预期表现低于其他交易规则的中位数时，它就是过拟合的。这和我们之前定义的PBO思想是一致的。[[Note for AFML C.11 - 回测的危险#PBO]]
但是，回测很难避免过拟合，尤其是在存在能够针对特定观测值的自由变量，或者$\Omega$中的元素数量较多时。同时，当$\Delta \pi_{i,t}$表现出序列相关性时，过拟合会导致样本外表现为负面。
### 我们的框架
我们感兴趣的是寻找一种最优交易规则（OTR），适用于那些过拟合最具破坏性的场景，比如表现出序列相关性时。具体来说时一个离散的Ornstein-Uhlenbeck（O-U）过程：
$$P_{i,t} = (1-\varphi)E_0[P_{i,T_i}] + \varphi P_{i,t-1} + \sigma \varepsilon_{i,t}$$
其中随机噪声$\varepsilon_{i,t}$独立同分布为标准高斯。根据$\pi_{i,t} = m_i(P_{i,t} - P_{i,0})$, 可以得到
$$\pi_{i,t} \sim \mathcal{N}\left[m_i((1-\varphi)E_0[P_{i,T_i}] \sum_{j=0}^{t-1} \varphi^j -P_{i,0}), m_i^2\sigma^2\sum_{j=0}^{t-1}\varphi^{2j} \right]$$
### 最优交易规则的数值确定
#### 算法
1. 使用线性方程估计$\{\sigma, \varphi\}$：
	$$P_{i,t} = E_0[P_{i,T_i}] + \varphi (P_{i,t-1} - E_0[P_{i,T_i}]) + \xi_t$$
2. 构建一个参数网格。一个好的方法是基于以上估计的$\hat{\sigma}$进行构造。
3. 使用估计参数$\{\hat{\sigma}, \hat{\varphi}\}$生成大量（比如100000）的路径， 基于种子$\{P_{i,0}, E_0[P_{i,T_i}]\}$. 因为我们不可以无限期持有，因此应该设定最大持有期限。
4. 对于每个路径，我们使用止盈止损，得到100000个$\pi_{i,T_i}$. 对于每组参数，计算对应的sharpe ratio.
5. 接下来有三种方式确定最优的参数组。
	1. 在参数组网格中找到最优的$R$,依赖于$\{\hat{\sigma}, \hat{\varphi}\}$和初始条件$\{P_{i,0}, E_0[P_{i,T_i}]\}$
	2. 如果策略$S$对特定机会$i$给定了利润目标，我们使用第四步的结果确定最佳止损。
	3. 同样的，如果止损被确定，我们可以用来搜索最佳止盈。

### 总结
我们展示了如何通过实验确定与遵循离散奥恩斯坦-乌伦贝克（O-U）过程的价格相关的最优交易策略。由于这种交易策略的推导并非源自历史模拟，我们的方法避免了将回测过度拟合于单一路径的风险。相反，最优交易规则是根据驱动价格的基础随机过程的特性推导出来的。**相同的方法也可以应用于除 O-U 过程之外的其他过程**。
**OTR猜想**：
对于由离散O-U过程描述的金融工具价格，存在唯一的最优交易规则，该规则在止盈和止损的组合下能够最大化交易规则的夏普比率。
证明上述猜想可能需要多年甚至几十年，但迄今为止进行的所有实验都在经验上证实了它。因此，理性的做法是假设该猜想是正确的，并通过合成数据来确定最优交易规则。在最坏的情况下，交易规则可能不是最优的，但几乎可以肯定，它仍然会比过拟合的交易规则表现更好。
