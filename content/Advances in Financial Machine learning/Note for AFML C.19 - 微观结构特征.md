## 微观结构特征
微观结构数据集包括有关拍卖过程的主要信息，例如订单取消、双向拍卖簿、排队、部分成交、激进方、更正、替换等。主要来源是金融信息交换（FIX）消息，可以从交易所购买。FIX消息中包含的详细信息使研究人员能够理解市场参与者如何隐藏和显示他们的意图。这使得微观结构数据成为构建预测性机器学习特征的重要组成部分之一。
### 文献综述
市场微观结构理论的深度和复杂性随着时间的推移而发展，这取决于可用数据的数量和多样性。第一代模型仅使用价格信息。那一时期的两个基础性成果是交易分类模型（如价格变动规则）和Roll模型。第二代模型出现于交易量数据开始可用之后，研究者将注意力转向研究交易量对价格的影响。
第三代模型出现在1996年之后，当时Maureen O’Hara、David Easley等人发表了他们的“信息交易概率”（PIN）理论。这构成了一个重大突破，因为PIN将买卖价差解释为流动性提供者（做市商）与持仓者（信息交易者）之间的连续战略决策的结果。本质上，它说明了市场做市商是被信息交易者不利选择（adversely selected）的期权的卖方，而买卖差价（bid-ask spread）就是他们为该期权收取的溢价。Easley 等人解释了如何估算 VPIN，这是基于成交量采样的高频 PIN 估计。
这些是微观结构文献中使用的主要理论框架。O’Hara和 Hasbrouck提供了低频微观结构模型的良好汇编。Easley 等人提出了高频微观结构模型的现代处理方法。

### 第一代：价格序列
第一代微观结构模型主要关注通过估计买卖价差和波动性来作为流动性不足的替代指标。他们使用的数据有限，并且在交易过程中没有设定战略性或顺序性的结构。
#### 跳动规则
跳动规则是一种用于确定交易主动方的算法。根据该逻辑，主动买入的交易标记为“1”，主动卖出的交易标记为“-1”:
$$b_t = 1, \text{ if } \Delta p_t >0;b_t = -1, \text{ if } \Delta p_t <0;b_t = b_{t-1}, \text{ if } \Delta p_t =0.$$
其中，$p_t$是成交价。许多研究表明，尽管“刻度规则”相对简单，但其分类准确率仍然很高。
$b_t$序列的变换可以生成有信息量的特征。这些变换包括：
1. 对未来期望值$E_t[b_t]$进行Kalman滤波
2. 对这些预测进行结构性突变检测
3. 计算$b_t$序列的熵
4. Wald-Wolfowitz 游程检验中$b_t$的t值
5. 累计$b_t$序列的分数阶差分
#### 卷轴模型
Roll是最早提出解释证券交易有效买卖价差的模型之一。Roll 的模型可以被视为测量证券流动性的早期尝试。考虑一个中间价序列$m_t$，价格遵循无飘逸的随机游走
$$m_t = m_{t-1} + u_t$$
这时价格变化$\Delta m_t = m_t -m_{t-1}$近似时标准正态分布$\Delta m_t \sim \mathcal{N}(0,\sigma_u^2).$ 
这些假设当然与所有的实证观察相悖，实证观察表明金融时间序列具有漂移性，它们是异方差的，表现出序列依赖性，并且它们的收益分布并非正态分布。但是如果采用适当的抽样程序，这些假设可能并非完全不现实[[Note for AFML C.2 - 数据结构#BARS]]. 对应的价格可以表示为
$$p_t = m_t + b_t c,$$
其中$c$是一半价差，$b_t \in \{-1,1\}$. Roll 模型假设买入和卖出同样可能，$P(b_t =1) = P(b_t =-1) = 1/2$, 且在时间序列上相互独立。在这些假设下，可以得到
$$\sigma^2(\Delta p_t) = E[(\Delta p_t)^2]-E[(\Delta p_t)]^2 = 2c^2 + \sigma_u^2,$$
$$\sigma(\Delta p_t, \Delta p_{t-1}) = -c^2.$$
由此可以导出$c = \sqrt{\max\{0,-\sigma(\Delta p_t, \Delta p_{t-1})\}}$和$\sigma_u^2 = \sigma(\Delta p_t) + 2\sigma(\Delta p_t, \Delta p_{t-1}).$
总之，买卖价差是价格变化序列协方差的函数，而真实（未观测到的）价格的噪声，排除微观结构噪声，是观测到的噪声与价格变化序列协方差的函数。
尽管存在局限性，Roll 模型仍在使用的一个原因是，它提供了一种相对直接的方法来确定那些交易稀少的证券，或者其公布报价不代表做市商愿意提供流动性的水平的有效买卖价差。利用 Roll 的估计值，我们可以推导出有关市场流动性状况的有用特征。
#### 高低波动率估算器
Beckers表明，基于最高价-最低价的波动率估计比基于收盘价的标准波动率估计更为准确。Parkinson推导出，对于遵循几何布朗运动的连续观察价格，
$$E\left[\frac{1}{T} \sum_{t=1}^T \left(\log (\frac{H_t}{L_t}) \right)^2 \right] = k_1 \sigma_{HL}^2,$$
$$E\left[\frac{1}{T} \sum_{t=1}^T \left(\log (\frac{H_t}{L_t}) \right) \right] = k_2 \sigma_{HL},$$
其中$k_1 = 4\log 2$, $k_2 = \sqrt{8/\pi}$, $H_t,L_t$分别是柱$t$的最高价和最低价。
#### Corwin and Schultz
Corwin和Schultz提出了从高低价的买卖价差估计器。估算基于两个主要因素：首先，高价与报价大致匹配，低价与报价大致匹配。高低价的比率反映了基本面波动率以及买卖价差。其次，高低价比中与波动性相关的成分随着两次观测之间的时间推移成正比增加。
Corwin 和 Schultz 表明，作为价格百分比的价差可以估算为
$$S_t = \frac{2(e^{\alpha_t} -1)}{1+e^{\alpha_t}},$$
其中
$$\alpha_t = \frac{\sqrt{2\beta_t} - \sqrt{\beta_t}}{3-2\sqrt{2}} - \sqrt{\frac{\gamma_t}{3-2\sqrt{2}}},$$
$$\beta_t = E\left[ \sum_{j=0}^1 \left( \log \left( \frac{H_{t-j}}{L_{t-j}} \right) \right)^2 \right],$$
$$\gamma_t = \left[ \log\left( \frac{H_{t-1,t}}{L_{t-1,t}}\right) \right]^2,$$
$H_{t-1,t}, L_{t-1,t}$是$t-1,t$柱上的最高价和最低价. 因为$\alpha_t < 0 \Rightarrow S_t <0$, 作者建议将负的$\alpha$设置为0. 
请注意，波动率并未出现在最终的 Corwin-Schultz 方程中。原因是波动率已被其高低估计值所取代。作为该模型的一个副产品，我们可以推导出 Becker-Parkinson 波动率，
$$\sigma = \left(\frac{\sqrt{2\beta_t} - \sqrt{\beta_t}}{3-2\sqrt{2}} + \sqrt{\frac{\gamma_t}{3-2\sqrt{2}}}\right)/k_2.$$
该程序在公司债券市场尤其有用，在该市场中没有集中交易簿，交易通过竞价买卖（BWIC）进行。由此产生的特点——买卖价差$S$，可以在滚动窗口中递归估算，并且可以使用卡尔曼滤波器对数值进行平滑处理。
### 第二代：策略交易模型
第二代微观结构模型侧重于理解和衡量流动性不足。流动性不足是金融机器学习模型中的一个重要信息特征，因为它是一种具有相关风险溢价的风险。这些模型相比第一代模型有更强的理论基础，因为它们将交易解释为信息充足和信息不足交易者之间的战略互动。在此过程中，它们关注有符号交易量和订单流失衡。
这些特征中的大多数是通过回归估计的。在实践中，我观察到，**与这些微观结构估计相关的t值比（平均）估计本身更具信息性。** 虽然文献中没有提到这一观察，但有充分理由更倾向于基于t值的特征而不是基于均值的特征：**t值通过估计误差的标准差重新缩放，包含了均值估计中所缺失的另一维信息。**
#### Kyle’s Lambda
Kyle 介绍了以下策略贸易模型。考虑一个末期价值为$v \sim \mathcal{N}(p_0,\Sigma_0)$的风险资产，以及两个交易者：
- 噪声交易者，交易数量为$u = \mathcal{N}(0,\sigma_u^2)$, 和$v$独立
- 知情交易者，知道$v$以及需求市价订单数$x$.
市场做市商观察到总订单流$y = x+u$, 并相应设定价格$p$. 在该模型中，做市商无法区分噪声交易者和知情交易者。他们根据订单流不平衡调整价格。价格变动和订单流不平衡之间存在正相关关系，这被称为市场影响。
知情交易者推测做市商具有线性价格调整函数，$p=\lambda y + \mu$, 其中$\lambda$是流动性度量的倒数。知情交易者的利润为$\pi = (v - p)x = (v-\lambda(x+u) -\mu)x$, 在$x = (v-\mu)/(2\lambda)$时达到最大值，条件为$\lambda >0$. (*这里难道忽略了$u$?*)
相反，做市商推测知情交易者的需求是$v$的线性函数, $x = \alpha + \beta v$, 这以为着$\alpha = -\mu/(2\lambda), \beta = 1/(2\lambda).$ 流动性越低意味着$\lambda$越高，这意味着知情交易者的需求越低。做市商必须在利润最大化和市场效率之间找到平衡(*具体时指什么？*)，并且在上述线性函数下，唯一可能的解出现在
$$\mu = p_0; \alpha = p_0 \sqrt{\frac{\sigma_u^2}{\Sigma_0}};\lambda = \frac{1}{2}\sqrt{\frac{\Sigma_0}{\sigma_u^2}};\beta = \sqrt{\frac{\sigma_u^2}{\Sigma_0}}.$$
最终得到知情交易者的期望收益为
$$E[\pi] = \frac{(v-p_0)^2}{2}\sqrt{\frac{\sigma_u^2}{\Sigma_0}} = \frac{1}{4\lambda}(v-p_0)^2.$$
这意味着知情交易者有三种盈利来源：
- 该证券定价错误。
- 噪声交易者净订单流的方差。噪声越大，信息交易者越容易隐藏自己的意图。
- 终端证券方差的倒数。波动性越低，套利定价错误就越容易实现收益。
在该模型中，变量$\lambda$反应的价格冲击。随着$v$的不确定性增加，流动性下降；随着噪声量的增加，流动性上升。作为一个特征，可以被最小二乘估计
$$\Delta p_t = \lambda (b_t V_t) + \varepsilon_t,$$
其中$p_t$是成交价序列，$b_t$是主动方方向，$V_t$是交易量。
#### Amihud’s Lambda
Amihud研究了绝对收益与流动性不足之间的正向关系。特别是，他计算了与一美元交易量相关的每日价格反应，并认为其数值是价格冲击的一个代理。这个想法的一个可能实现是
$$|\Delta(\log \tilde{p}_\tau)| = \lambda \sum_{t \in B_\tau}(p_t V_t) + \varepsilon_\tau,$$
其中$B_\tau$是柱$\tau$中的交易集合，$\tilde{p}_\tau$是柱$\tau$的收盘价, $p_t V_t$是交易额。尽管表面上看起来很简单，Hasbrouck发现日频 Amihud lambda 的估计值表现出与日内有效价差估算有很高的秩相关性。
#### Hasbrouck’s Lambda
Hasbrouck继承了 Kyle 和 Amihud 的观点，并将其应用于基于交易和报价（TAQ）数据的价格冲击系数估计。他使用 Gibbs 采样器来对回归模型进行贝叶斯估计
$$\log \tilde{p}_{i,\tau} - \log \tilde{p}_{i,\tau-1} = \lambda_i \sum_{t\in B_{i,\tau}}(b_{i,t}\sqrt{p_{i,t}V_{i,t}}) + \varepsilon_{i,\tau},$$
其中$B_{i,\tau}$是证券$i$在柱$\tau$中的交易的集合，其余类似同上。我们可以对每一个证券$i$估计一个$\lambda_i$作为特征来估计实际的交易成本。
与大多数文献一致，Hasbrouck 建议使用 5 分钟时间间隔进行刻度采样。然而，出于第 2 章讨论的原因，通过与市场活动同步的随机采样方法可以获得更好的结果。
### 第三代：序列交易模型
策略交易模型通常有一个信息充分的交易者，可以在多个时间点进行交易。在本节中，我们将讨论另一种模型，其中随机选出的交易者依次、独立地进入市场。
自从出现以来，顺序交易模型在做市商中变得非常受欢迎。其中一个原因是，它们考虑了流动性提供者所面临的不确定性来源，即信息事件发生的概率、此类事件为负面的概率、噪声交易者的到达率以及知情交易者的到达率。通过这些变量，做市商必须动态更新报价，并管理他们的库存。
#### 基于信息的交易概率
Easley 等人使用交易数据来确定个别证券基于信息交易的概率 (PIN)。该微观结构模型将交易视为做市商和持仓者之间的博弈，并在多个交易期内重复进行。
记证券价格为$S$, 目前的价值为$S_0$. 一旦有新的信息进入市场，$S$将会是$S_B$(坏消息)或$S_G$(好消息)。在关注的时间范围内出现新信息的概率为$\alpha$, 消息为坏消息的概率为$\delta$, 好消息的概率为$1-\delta$. 可以得到证券价格在时间$t$的期望为
$$E[S_t] = (1-\alpha_t)S_t + \alpha_t (\delta_t S_B + (1-\delta_t) S_G).$$
假设泊松分布，知情交易者的到达率为$\mu$, 非知情者的到达率为$\varepsilon$. 为了避免因知情交易者而造成损失，做市商达到盈亏平衡的bid价格为
$$E[B_t] = E[S_t] - \frac{\mu \alpha_t \delta_t}{\varepsilon + \mu\alpha_t\delta_t}(E[S_t] - S_B),$$
达到盈亏平衡的ask价格为
$$E[A_t] = E[S_t] + \frac{\mu \alpha_t (1-\delta_t)}{\varepsilon + \mu \alpha_t(1-\delta_t)}(S_G - E[S_t]).$$
由此可得，盈亏平衡买卖差价的确定方式为
$$E[A_t-B_t] = \frac{\mu \alpha_t (1-\delta_t)}{\varepsilon + \mu \alpha_t(1-\delta_t)}(S_G - E[S_t]) + \frac{\mu \alpha_t \delta_t}{\varepsilon + \mu\alpha_t\delta_t}(E[S_t] - S_B).$$
对于标准情形$\delta_t = 1/2$, 有$E[A_t - B_t] = \frac{\alpha_t \mu}{\alpha_t \mu + 2\varepsilon}(S_G -S_B).$ 
这个方程告诉我们，决定做市商提供流动性价格范围的关键因素是
$$PIN_t = \frac{\alpha_t \mu}{\alpha_t \mu + 2\varepsilon},$$下标 $t$ 表示概率 $\alpha$ 和 $\delta$ 是在该时间点估计的。
为了确定$PIN_t$，需要估计$\{\alpha,\delta,\mu,\varepsilon\}$. 一种最大似然方法是拟合三项泊松分布的混合模型，
$$P(V^B,V^S) = (1-\alpha)P(V^B,\varepsilon)P(V^S,\varepsilon) + \alpha(\delta P(V^B,\varepsilon)P(V^S,\mu+\varepsilon)+(1-\delta)P(V^B,\mu+\epsilon)P(V^S,\varepsilon)),$$
其中$V^B$是与卖价(ask)成交的成交量，$V^S$是与买价(ask)成交的成交量。(*没看懂怎么估计的*)
#### 成交量同步知情交易概率
Easley 等人证明了
$$E[V^B -V^S] = (1-\alpha)(\varepsilon - \varepsilon) + \alpha(1-\delta)(\varepsilon - (\mu + \varepsilon )) + \alpha\delta(\mu+\varepsilon-\varepsilon) = \alpha \mu (1-2\delta) \approx \alpha\mu,$$
当$\mu$很大时。Easley 等人提出了 PIN 的高频估计方法，他们将其命名为与成交量同步的知情交易概率（VPIN）。该方法采用成交量时钟，将数据采样与市场活动（通过成交量体现）同步。然后我们可以估计
$$\frac{1}{n}\sum_{\tau =1}^{n} |V_\tau^B - V_\tau^S| \approx \alpha\mu.$$
因为所有的成交量柱都是相同大小的 V，我们知道根据构造
$$\frac{1}{n}\sum_{\tau=1}^n (V_\tau^B + V_\tau^S) = V = \alpha \mu + 2\varepsilon.$$
得到估计量
$$VPIN_\tau = \frac{\sum_{\tau =1}^{n} |V_\tau^B - V_\tau^S|}{nV}.$$

### 来自微观结构数据集的附加特征
我们之前研究的特征是由市场微观结构理论提出的。此外，我们还应考虑其他特征，虽然这些特征不是理论所建议的，但我们怀疑它们包含有关市场参与者操作方式及其未来意图的重要信息。在此过程中，我们将利用机器学习算法的强大功能，这些算法可以学习如何使用这些特征，而无需理论的具体指导。
#### 订单规模分布
Easley 等人研究了每笔交易规模对应的交易频率，发现整数倍交易规模的交易异常频繁。这种模式并非“硅基交易者”的典型行为，后者通常会通过程序随机化交易以掩盖其在市场中的踪迹。
一个有用的特征可能是确定标准规模交易的正常频率，并监控偏离该预期值的情况。例如，机器学习算法可以确定是否较高比例的标准规模交易与趋势相关，因为人类交易者往往会根据基本面观点、信念或信心进行下注。相反，比平时较低比例的标准规模交易可能会增加价格横盘的可能性，因为硅基交易者通常不会持有长期观点。
#### 取消率、限价订单、市价订单
Easley 等人研究了市价单、限价单和报价取消的影响。他们发现，小盘股和大盘股对这些事件的反应不同。他们得出结论，衡量这些幅度对于模拟买卖价差的动态是相关的。
Easley 等人还认为，高频报价取消率可能表明流动性较低，因为参与者发布的报价并不打算被成交。他们讨论了四类掠夺性算法：
1. **报价干扰者**：他们从事“延迟套利”。他们的策略是通过向交易所发送大量信息来压制竞争算法，目的是让这些算法处理只有信息发送者自己知道可以忽略的消息，从而变慢。
2. **报价悬挂者**：这种策略发送的报价迫使被挤压的交易者追逐与其利益相违背的价格。
3. **流动性挤压者**：当一位陷入困境的大投资者被迫清算其持仓时，掠夺性算法会沿着相同的方向交易，尽可能抽干流动性。结果，价格被过度推动，他们从中获利。
4. **群体捕食者**：独立狩猎的掠食者会意识到彼此的活动，并组成一个群体，以最大化触发连锁反应的机会。NANEX显示，似乎有群体捕食者在迫使止损。尽管他们的个人行为太小，不足以引起监管机构的怀疑，但他们的集体行动可能是市场操纵。当情况如此时，很难证明他们的共谋，因为他们是以分散、自然的方式协调行动的。
这些掠夺性算法利用报价撤销和各种订单类型，试图对做市商进行不利选择。它们在交易记录中留下不同的特征，通过测量报价撤销率、限价单和市价单的比率，可以作为有用的特征，反映其意图。
#### 时间加权平均价格执行算法
Easley 等人展示了如何识别针对特定时间加权平均价格（TWAP）的执行算法。TWAP 算法是一种将大订单切分为小订单，并以固定时间间隔提交的小订单算法，目的是达到预定的时间加权平均价格。
将一天划分为 24 小时，然后在每小时内将每秒的交易量相加，而不区分分钟。随后，将这些总交易量绘制成三维曲面，其中 x 轴表示每秒交易量，y 轴表示一天中的小时，z 轴表示总交易量。通过这一分析，我们可以观察到随着一天的推移，每分钟的交易量分布，并寻找在时间-空间上执行其大额订单的低频交易者。
一个有用的机器学习功能可能是在每分钟开始时评估订单不平衡，并确定是否存在持续的成分。这可以用来抢先交易大型机构投资者，同时他们的大部分TWAP订单仍在等待中。
#### 期权市场
由看涨-看跌平价报价隐含的基础买卖价差，并将其与股票的实际买卖价差进行比较，其中存在分歧。分歧往往会以股票报价为准解决，这意味着期权报价不包含经济上显著的信息。期权交易包含股票价格未包括的信息。
相对昂贵的看涨期权的股票（同时具有高波动率差价和波动率差价变化大的股票）每周的表现比相对昂贵的看跌期权的股票（同时具有低波动率差价和波动率差价变化小的股票）高出 50 个基点。
根据这些观察，可以从计算期权交易中推导出的买入卖出隐含股票价格中提取有用的特征。期货价格仅代表未来的平均或预期值。但期权价格可以让我们推导出所定价结果的整个分布。机器学习算法可以在不同行权价和到期日的希腊字母报价中寻找模式。
#### 有符号订单流的序列相关性
Toth 等人研究了伦敦证券交易所股票的买卖单符号流，并发现订单符号在多天内呈正自相关。他们将这一现象归因于两个可能的解释：羊群效应和拆分订单。他们得出结论，在不到几小时的时间尺度上，订单流的持续性主要是由于拆分订单，而非羊群效应。
鉴于市场微观结构理论将订单流不平衡的持续性归因于信息交易者的存在，通过**符号成交量的序列相关性**来衡量这种持续性的强度是合理的。
### 什么是微观结构信息？
考虑一个特征矩阵 $X = \{X_t\}_{t=1,...,T}$，它包含了市场做市商通常用来决定是否在某个价格水平提供流动性或取消其被动报价的信息。首先，我们推导出一个数组$y = {y_t}_{t=1,...,T}$，对导致做市利润的观察赋值为 1，对导致做市亏损的观察赋值为 0. 其次，我们在训练集 $(X, y)$上拟合分类器。第三，当新的样本外观察值到达$\tau > T$时，我们使用拟合的分类器来预测标签$\hat{y}_\tau = E_\tau[y_\tau|X]$。第四，推导这些预测的交叉熵损失$L_\tau$。第五，对负交叉熵损失数组$\{-L_t\}_{t=T+1,...,\tau}$ 拟合核密度估计器 (KDE)，以推导其累积分布函数$F$。第六，在时间 t 估计微观结构信息为$\phi_\tau = F(-L_\tau)$ ，其中$\phi_\tau \in (0,1).$

这种微观结构信息可以理解为市场做市商决策模型所面临的复杂性。在正常市场条件下，市场做市商会生成低交叉熵损失的知情预测，并能够通过为持仓者提供流动性来获利。然而，在存在（不对称地）知情交易者的情况下，市场做市商会产生高交叉熵损失的非知情预测，从而面临逆向选择。换句话说，**微观结构信息只能相对于市场做市商的预测能力来定义和衡量**。因此，$\phi_tau$应该成为你金融机器学习工具包中的一个重要特征。
