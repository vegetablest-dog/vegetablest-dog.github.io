## 微观结构特征
微观结构数据集包括有关拍卖过程的主要信息，例如订单取消、双向拍卖簿、排队、部分成交、激进方、更正、替换等。主要来源是金融信息交换（FIX）消息，可以从交易所购买。FIX消息中包含的详细信息使研究人员能够理解市场参与者如何隐藏和显示他们的意图。这使得微观结构数据成为构建预测性机器学习特征的重要组成部分之一。
### 文献综述
市场微观结构理论的深度和复杂性随着时间的推移而发展，这取决于可用数据的数量和多样性。第一代模型仅使用价格信息。那一时期的两个基础性成果是交易分类模型（如价格变动规则）和Roll模型。第二代模型出现于交易量数据开始可用之后，研究者将注意力转向研究交易量对价格的影响。
第三代模型出现在1996年之后，当时Maureen O’Hara、David Easley等人发表了他们的“信息交易概率”（PIN）理论。这构成了一个重大突破，因为PIN将买卖价差解释为流动性提供者（做市商）与持仓者（信息交易者）之间的连续战略决策的结果。本质上，它说明了市场做市商是被信息交易者不利选择（adversely selected）的期权的卖方，而买卖差价（bid-ask spread）就是他们为该期权收取的溢价。Easley 等人解释了如何估算 VPIN，这是基于成交量采样的高频 PIN 估计。
这些是微观结构文献中使用的主要理论框架。O’Hara和 Hasbrouck提供了低频微观结构模型的良好汇编。Easley 等人提出了高频微观结构模型的现代处理方法。

### 第一代：价格序列
第一代微观结构模型主要关注通过估计买卖价差和波动性来作为流动性不足的替代指标。他们使用的数据有限，并且在交易过程中没有设定战略性或顺序性的结构。
#### 跳动规则
跳动规则是一种用于确定交易主动方的算法。根据该逻辑，主动买入的交易标记为“1”，主动卖出的交易标记为“-1”:
$$b_t = 1, \text{ if } \Delta p_t >0;b_t = -1, \text{ if } \Delta p_t <0;b_t = b_{t-1}, \text{ if } \Delta p_t =0.$$
其中，$p_t$是成交价。许多研究表明，尽管“刻度规则”相对简单，但其分类准确率仍然很高。
$b_t$序列的变换可以生成有信息量的特征。这些变换包括：
1. 对未来期望值$E_t[b_t]$进行Kalman滤波
2. 对这些预测进行结构性突变检测
3. 计算$b_t$序列的熵
4. Wald-Wolfowitz 游程检验中$b_t$的t值
5. 累计$b_t$序列的分数阶差分
#### 卷轴模型
Roll是最早提出解释证券交易有效买卖价差的模型之一。Roll 的模型可以被视为测量证券流动性的早期尝试。考虑一个中间价序列$m_t$，价格遵循无飘逸的随机游走
$$m_t = m_{t-1} + u_t$$
这时价格变化$\Delta m_t = m_t -m_{t-1}$近似时标准正态分布$\Delta m_t \sim \mathcal{N}(0,\sigma_u^2).$ 
这些假设当然与所有的实证观察相悖，实证观察表明金融时间序列具有漂移性，它们是异方差的，表现出序列依赖性，并且它们的收益分布并非正态分布。但是如果采用适当的抽样程序，这些假设可能并非完全不现实[[Note for AFML C.2 - 数据结构#BARS]]. 对应的价格可以表示为
$$p_t = m_t + b_t c,$$
其中$c$是一半价差，$b_t \in \{-1,1\}$. Roll 模型假设买入和卖出同样可能，$P(b_t =1) = P(b_t =-1) = 1/2$, 且在时间序列上相互独立。在这些假设下，可以得到
$$\sigma^2(\Delta p_t) = E[(\Delta p_t)^2]-E[(\Delta p_t)]^2 = 2c^2 + \sigma_u^2,$$
$$\sigma(\Delta p_t, \Delta p_{t-1}) = -c^2.$$
由此可以导出$c = \sqrt{\max\{0,-\sigma(\Delta p_t, \Delta p_{t-1})\}}$和$\sigma_u^2 = \sigma(\Delta p_t) + 2\sigma(\Delta p_t, \Delta p_{t-1}).$
总之，买卖价差是价格变化序列协方差的函数，而真实（未观测到的）价格的噪声，排除微观结构噪声，是观测到的噪声与价格变化序列协方差的函数。
尽管存在局限性，Roll 模型仍在使用的一个原因是，它提供了一种相对直接的方法来确定那些交易稀少的证券，或者其公布报价不代表做市商愿意提供流动性的水平的有效买卖价差。利用 Roll 的估计值，我们可以推导出有关市场流动性状况的有用特征。
#### 高低波动率估算器
Beckers表明，基于最高价-最低价的波动率估计比基于收盘价的标准波动率估计更为准确。Parkinson推导出，对于遵循几何布朗运动的连续观察价格，
$$E\left[\frac{1}{T} \sum_{t=1}^T \left(\log (\frac{H_t}{L_t}) \right)^2 \right] = k_1 \sigma_{HL}^2,$$
$$E\left[\frac{1}{T} \sum_{t=1}^T \left(\log (\frac{H_t}{L_t}) \right) \right] = k_2 \sigma_{HL},$$
其中$k_1 = 4\log 2$, $k_2 = \sqrt{8/\pi}$, $H_t,L_t$分别是柱$t$的最高价和最低价。
#### Corwin and Schultz
Corwin和Schultz提出了从高低价的买卖价差估计器。估算基于两个主要因素：首先，高价与报价大致匹配，低价与报价大致匹配。高低价的比率反映了基本面波动率以及买卖价差。其次，高低价比中与波动性相关的成分随着两次观测之间的时间推移成正比增加。
Corwin 和 Schultz 表明，作为价格百分比的价差可以估算为
$$S_t = \frac{2(e^{\alpha_t} -1)}{1+e^{\alpha_t}},$$
其中
$$\alpha_t = \frac{\sqrt{2\beta_t} - \sqrt{\beta_t}}{3-2\sqrt{2}} - \sqrt{\frac{\gamma_t}{3-2\sqrt{2}}},$$
$$\beta_t = E\left[ \sum_{j=0}^1 \left( \log \left( \frac{H_{t-j}}{L_{t-j}} \right) \right)^2 \right],$$
$$\gamma_t = \left[ \log\left( \frac{H_{t-1,t}}{L_{t-1,t}}\right) \right]^2,$$
$H_{t-1,t}, L_{t-1,t}$是$t-1,t$柱上的最高价和最低价. 因为$\alpha_t < 0 \Rightarrow S_t <0$, 作者建议将负的$\alpha$设置为0. 
请注意，波动率并未出现在最终的 Corwin-Schultz 方程中。原因是波动率已被其高低估计值所取代。作为该模型的一个副产品，我们可以推导出 Becker-Parkinson 波动率，
$$\sigma = \left(\frac{\sqrt{2\beta_t} - \sqrt{\beta_t}}{3-2\sqrt{2}} + \sqrt{\frac{\gamma_t}{3-2\sqrt{2}}}\right)/k_2.$$
该程序在公司债券市场尤其有用，在该市场中没有集中交易簿，交易通过竞价买卖（BWIC）进行。由此产生的特点——买卖价差$S$，可以在滚动窗口中递归估算，并且可以使用卡尔曼滤波器对数值进行平滑处理。
### 第二代：策略贸易模型
第二代微观结构模型侧重于理解和衡量流动性不足。流动性不足是金融机器学习模型中的一个重要信息特征，因为它是一种具有相关风险溢价的风险。这些模型相比第一代模型有更强的理论基础，因为它们将交易解释为信息充足和信息不足交易者之间的战略互动。在此过程中，它们关注有符号交易量和订单流失衡。
这些特征中的大多数是通过回归估计的。在实践中，我观察到，**与这些微观结构估计相关的t值比（平均）估计本身更具信息性。** 虽然文献中没有提到这一观察，但有充分理由更倾向于基于t值的特征而不是基于均值的特征：**t值通过估计误差的标准差重新缩放，包含了均值估计中所缺失的另一维信息。**
