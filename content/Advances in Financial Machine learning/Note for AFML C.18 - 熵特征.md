## 熵特征
*当市场不完全时，价格是基于部分信息形成的，由于某些交易者比其他人掌握更多信息，他们可以利用这种信息不对称。估计价格序列中所含信息的数量并根据这些信息构建特征以供机器学习算法预测可能的结果将会非常有帮助。*
### 香农熵
熵定义为由一个平稳数据源产生的平均信息量。数学上表示为
$$H(X) = -\sum p(x)log_2p(x)$$
 这种设计来自于这样一个观察：低概率事件比高概率事件提供更多信息。换句话说，当发生意料之外的事情时，我们会获得新的知识。冗余被定义为
 $$R(X) = 1-\frac{H(X)}{\log_2 \|A\|},$$
 其中$\|A\|$表示所有可能取值的个数。
 两个变量之间的互信息被定义为联合概率密度与边际概率密度乘积之间的KL散度。
 $$MI(X,Y) = E_{f(x,y)}[\log \frac{f(x,y)}{f(x)}f(y)] = H(X)+H(Y)-H(X,Y).$$
 互信息（MI）总是非负的、对称的，并且当且仅当 X 和 Y 独立时等于零。对于正态分布的变量，互信息与熟知的皮尔逊相关系数 𝜌 密切相关， $MI(X,Y) = -\log(1-\rho^2)/2.$ 因此，互信息是衡量变量之间关联的自然方法，**无论它们的性质是线性还是非线性的**.
### 插件式（或最大似然）估计器
*这里用了一种新的序列表达方式。*
给定一个序列$x_1^n$,在该序列中形成一个所有长度$w<n$的单词字典$A^w$. 考虑任意一个单词$y_1^w \in A^w$. 记$\hat{p}_w(y_1^w)$为单词$y_1^w$在$x_1^n$中的经验概率。假设数据是平稳且遍历的过程生成的，大数定律保证的经验分布接近正式分布。则熵率（每个比特的平均熵）的自然估计量为
$$\hat{H}_{n,w} = -\frac{1}{w} \sum_{y_{1}^w \in A^w} \hat{p}_w(y_1^w) \log_2 \hat{p}_w(y_1^w).$$值$w$应该足够大，使得$\hat{H}_{n,w}$接近真实熵$H$. $n$的值应该远大于$w$, 这样经验分布才接近真实分布。

### 熵的金融应用
#### 市场效率
一个序列的熵率决定了其最佳压缩率。熵越高，冗余越低，信息含量越大。因此，价格序列的熵告诉我们特定时间点的市场效率程度。泡沫出现在压缩（低熵）市场中。
#### 最大熵生成
在所有可能的未来结果中，熵最大化的那个结果可能是最有利可图的，因为它是最不可能被频率统计模型预测到的。它就是最有可能触发止损的黑天鹅情景，从而产生一种反馈机制，强化并加剧价格走势，导致收益时间序列的符号出现连续变化。
#### 投资组合集中度
基于因子pca分解的主成分权重，基于熵的计算方式构造的集中度衡量。
$$H = 1- \frac{1}{N} e^{-\sum_{n=1}^{N} \theta_i \log \theta_i}.$$
#### 市场微观结构
当好消息与坏消息的概率相等时，可知知情交易的概率为
$$PIN = \frac{\alpha \mu}{\alpha \mu + 2 \varepsilon},$$
其中$\mu$是消息交易者到达的速率，$\varepsilon$是无知交易者的到达速率，$\alpha$是信息事件的概率。PIN可以理解为来自知情交易者的订单占总订单流的比例。
在大小为$V$的成交量柱中，将每一笔成交划分为买入或卖出。设$V_\tau^B$是成交量柱$\tau$中所有买入成交量的总和，$V_\tau^S$为所有卖出成交量的综合。有$E[|V_\tau^B - V_\tau^S|] \approx \alpha \mu$ 和$E[V_\tau^B + V_\tau^S] = \alpha \mu + 2\varepsilon$. 可以得到
$$VPIN = \frac{\alpha\mu}{\alpha\mu + 2\varepsilon} = \frac{E[|2V_\tau^B - V|]}{V}.$$
这其实就是订单流的不平衡的绝对值。VPIN 理论为知情交易概率（PIN）与在成交量时钟下订单流失衡的持续性之间提供了一个正式的联系。
持续的订单流不平衡是逆向选择的必要但不充分条件。为了让做市商向有信息的交易者提供流动性，该订单流不平衡$|OI_\tau|$也必须相对不可预测。为了确定逆向选择的概率，我们必须确定订单流不平衡有多不可预测。
考虑一长串符号。当该序列包含很少的冗余模式时，它包含了一定程度的复杂性，使得描述和预测变得困难。我们可以利用序列的冗余性与其不可预测性（对于做市商而言）之间的这种联系，来推导逆向选择的概率。
给定一个以$\tau = 1,...,N$为索引的成交量序列，每个成交量为$V$，我们确定买入成交量比例为$v_\tau^B$. 计算$v_\tau^B$的$q$分位数，定义$q$个不相交的自己$K = \{K_1, ...,K_q\}$. 构造应声将每个$v_\tau^B$对应到不相交的子集之一, $f:v_\tau^B \to \{1,...,q\}$. 将成交量比例序列量子化为$X = (f(v_1^B),...,f(v_N^B)).$ 使用Kontoyiannis 的 Lempel-Ziv 算法估计熵$H(X)$. 计算累计分布函数$F(H(X))$并将$F(H(X_\tau))$作为序列特征，用于预测逆向选择。
